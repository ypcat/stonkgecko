# 🦎 stonkgecko

A CoinGecko-inspired stock tracker for the **world's top 10 stock markets**, with each
market's largest companies ranked by **market capitalization**. The entire site is
generated by a single self-contained Elixir script and republished **daily** to GitHub
Pages by a GitHub Action.

## How it works

- **`build.exs`** — one self-contained Elixir script (`Mix.install([:req])`, no project,
  no deps file). It fetches live prices, computes/ranks market caps, and writes a static
  `public/index.html`.
- **`.github/workflows/deploy.yml`** — runs `elixir build.exs` on a daily cron
  (`06:00 UTC`), on every push to `main`, and on manual dispatch, then deploys `public/`
  to GitHub Pages.

### Data sources (no API key required)

1. **Live price** comes from Yahoo Finance's `v8/finance/chart` endpoint — the most
   reliable no-key source.
2. **Market cap** = `price × shares_outstanding` (share counts are embedded in the
   script as a slow-moving fallback), then converted to **USD** via live FX rates.
3. The script *opportunistically* tries Yahoo's `v7/finance/quote` endpoint (cookie +
   crumb handshake) to override with the **exact** reported market cap when reachable.
4. **Optional:** set a `FMP_API_KEY` repo secret to prefer
   [Financial Modeling Prep](https://financialmodelingprep.com/) market caps.

Ranking is **within each market** (so it never depends on FX). The combined-market-cap
stat is in USD. If an endpoint is unreachable the script degrades gracefully rather than
crashing.

## One-time setup

1. **Enable Pages:** repo **Settings → Pages → Build and deployment → Source = GitHub Actions**.
2. **Custom domain (stonkgecko.com):** the build writes a `CNAME` file automatically.
   Point DNS at GitHub Pages:
   - apex `stonkgecko.com` → A records `185.199.108.153`, `185.199.109.153`,
     `185.199.110.153`, `185.199.111.153` (and AAAA for IPv6 if desired).
   - `www` → CNAME to `<user>.github.io`.
   Then confirm the domain under Settings → Pages.
3. *(Optional)* Add `FMP_API_KEY` under **Settings → Secrets and variables → Actions**.

## Run locally

```bash
elixir build.exs      # requires Elixir 1.17+ / OTP 27, writes public/index.html
```

Open `public/index.html` in a browser.

## Customizing

- **Markets / tickers:** edit `Stonk.markets/0`.
- **Share counts & display names:** edit `Stonk.meta/0`.
- **Look & feel:** edit `Render.css/0`.
